# Get item UIDs mapped by fields

Get item UIDs mapped by fields

## Usage

``` r
fetch_item_mapping_fields(version = "current")
```

## Arguments

- version:

  Redivis version tag of the `levante_metadata_items` dataset

## Examples

``` r
if (FALSE) { # \dontrun{
mapping_fields <- fetch_item_mapping_fields()
} # }
```
