# Get item UIDs mapped by trial_id

Get item UIDs mapped by trial_id

## Usage

``` r
fetch_item_mapping_trial(version = "current")
```

## Arguments

- version:

  Redivis version tag of the `levante_metadata_items` dataset

## Examples

``` r
if (FALSE) { # \dontrun{
mapping_trial <- fetch_item_mapping_trial()
} # }
```
