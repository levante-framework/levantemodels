# Get item UIDs mapped by item_id

Get item UIDs mapped by item_id

## Usage

``` r
fetch_item_mapping_id(version = "current")
```

## Arguments

- version:

  Redivis version tag of the `levante_metadata_items` dataset

## Examples

``` r
if (FALSE) { # \dontrun{
mapping_id <- fetch_item_mapping_id()
} # }
```
